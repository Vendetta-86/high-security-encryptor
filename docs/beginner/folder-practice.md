# 文件夹加密与恢复：GUI 跟练

- **预计时间：**约 15 分钟
- **适用对象：**已完成[第一次使用练习](first-run.md)的用户
- **需要准备：**主 GUI、一个可删除的练习文件夹、两个虚构文本文件
- **练习数据：**只用临时文件和虚构口令

这次练习使用主 GUI 的“快速使用”页签处理整个文件夹，不需要 JSON 配置。程序会将文件夹打成一个 `.zip.hse` 文件；解密时会恢复到新的目录。不要拿唯一副本或重要资料练习。

## 1. 准备样例目录

在临时目录 `HSE-文件夹练习` 中创建：

```text
待加密/
├─ note.txt
└─ 子目录/
   └─ detail.txt
```

给两个文本写入不同的虚构内容。记下目录结构和内容，准备一个只用于本次练习的虚构口令。

## 2. 加密整个文件夹

1. 打开 `high-security-encryptor-gui.exe`，选择“快速使用”。
2. 在“我要”中选择“加密”。
3. 点击“选择文件夹”，选择 `待加密` 文件夹本身。
4. 在“主加密密码”和“确认主加密密码”中输入同一组虚构口令。
5. 点击“一键开始”，等待日志显示成功，并记下日志中的 `.zip.hse` 输出路径。

**预期结果：**原文件夹和两个原始文本仍在；其旁边新出现一个 `.zip.hse` 文件。GUI 会自动选择未使用的输出名，不会覆盖已有输出。

## 3. 解密并检查目录结构

1. 在“快速使用”中把“我要”改为“解密”。
2. 选择第 2 步日志记录的 `.zip.hse`，输入同一组虚构口令，然后点击“一键开始”。
3. 从日志读取实际恢复目录。恢复目录名通常是密文名加 `_decrypted`；若已存在同名目录，程序会另选一个可用名称。
4. 打开恢复目录，确认其中有 `note.txt` 和 `子目录\detail.txt`。
5. 逐字比较两份恢复内容和原件，并确认目录层级一致。

**完成目标：**恢复目录包含完整的两份样例内容和原有嵌套关系；原始输入目录仍未改变。人工比对确认的是这个样例的可读内容，不等同于独立审计或介质级安全删除。

## 常见问题

| 现象 | 处理方式 |
|---|---|
| 选错输入对象 | 加密时选择原文件夹；解密时选择 `.zip.hse`。普通 `.hse` 是单文件密文，不能替代文件夹包。 |
| 口令认证失败 | 确认选择的是本次输出包，并检查键盘布局和虚构口令记录；不要把失败结果当作已恢复文件。 |
| 恢复目录名字和预想不同 | 按运行日志中的路径打开；冲突时程序会改用新的目录名。 |
| 只找到空目录或内容不全 | 先停止并保留原件与 `.zip.hse`，检查日志中的失败步骤；不要删除输入或反复覆盖输出。 |

完成后，确认临时目录中没有需要保留的内容，再自行删除整个 `HSE-文件夹练习`。
