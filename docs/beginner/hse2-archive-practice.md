# 独立 HSE2 GUI：创建、校验、检查并恢复归档

本练习使用独立的 `high-security-encryptor-hse2-gui`，学习普通 HSE2 v2 归档的基本流程。它不涉及 v5 双视图、keyfile、DPAPI 或 wrapper 管理；这些功能有各自的风险和设置。

## 练习目标

在临时目录中创建一个 HSE2 归档，运行完整校验与元数据检查，再恢复到另一个空目录，并核对恢复内容。整个练习保留原始文件和归档。

## 1. 准备虚构样例

1. 在桌面新建 `HSE2-练习` 文件夹。
2. 在其中新建 `待加密` 文件夹，再新建 `子目录`。
3. 在 `待加密` 中创建 `说明.txt`，写入 `HSE2 practice alpha`；在 `待加密\子目录` 中创建 `内容.txt`，写入 `HSE2 practice beta`。
4. 本练习使用一次性虚构口令，例如 `HSE2-training-only-4821`。不要输入真实账户密码或复用真实口令。

预期准备结构：

```text
HSE2-练习/
└─ 待加密/
   ├─ 说明.txt
   └─ 子目录/
      └─ 内容.txt
```

## 2. 创建归档

1. 打开独立 HSE2 GUI，在动作下拉框选择“创建 HSE2 归档”。确认当前动作名称，避免误选其他 HSE2 操作。
2. “要加密的文件夹”选择 `HSE2-练习\待加密`。
3. “输出文件”设置为尚不存在的 `HSE2-练习\练习.hse2`。不要把归档写进待加密文件夹内部，也不要启用“允许覆盖输出文件”。
4. “容器格式版本”保留默认值 `2`；“归档密码安全等级”保留默认“推荐高安全”。格式版本决定归档布局；安全等级影响口令派生成本，两者不是同一个设置。
5. 在“归档密码（可选）”和“确认归档密码”中输入相同的虚构口令。虽然界面允许其他解锁方式，本入门练习只用口令。
6. 保留默认启用的“创建后校验归档（不写出明文）”，然后运行操作。确认输出成功，且练习目录中出现 `练习.hse2`。

如果口令为空、确认不一致、路径无效或目标文件已存在，先按提示修正；不要为了继续而覆盖未知文件。

## 3. 完整校验与检查元数据

1. 将动作改为“完整校验 HSE2 归档”，在“输入文件 / .hse2 容器”选择 `练习.hse2`，输入同一个口令，然后运行。
2. 成功表示程序已认证归档中的加密内容；本操作不输出明文文件。
3. 再将动作改为“检查 HSE2 元数据”，选择同一个归档并运行。此动作不需要口令，显示归档结构信息，不会解密或恢复文件。
4. 检查结果中的版本、文件数和数据块数量等字段。元数据可能泄露归档结构或大小信息；不要把原始诊断输出公开发布。

注意：“HSE2 只读校验”是检查配置文件规则的另一项动作；它不校验 `.hse2` 归档。创建后的自动校验、手动“完整校验 HSE2 归档”和元数据检查用途也不同。

## 4. 恢复到新目录并核对

1. 将动作改为“解密并打开 HSE2 归档”。输入同一个 `练习.hse2`，在“输出文件”路径选择尚不存在的 `HSE2-练习\恢复结果` 文件夹，并输入同一口令。
2. 保留“打开前完整校验归档”选项（如果当前界面已启用）。确认输出目标无重要文件后运行。
3. 打开 `恢复结果\待加密`，检查 `说明.txt` 与 `子目录\内容.txt` 均存在，并逐字核对文本分别为 `HSE2 practice alpha`、`HSE2 practice beta`。
4. 确认原始 `待加密` 文件夹和 `练习.hse2` 仍在。不要用练习结果替换唯一原件。

手动比对样例内容是本练习的可见性检查，不是对程序进行独立审计，也不证明任何其他归档都能恢复。

## 5. 常见结果与排查

- **完整校验认证失败：**先确认选择的归档和口令；不要通过覆盖、改名或反复试真实口令来绕过问题。
- **恢复目标已存在：**改用新的空目录。练习中不要打开覆盖选项。
- **元数据检查成功但恢复失败：**元数据检查不解锁内容，也不证明凭据可用；使用完整校验和正确口令重新判断。
- **不确定当前动作会写什么：**停止运行，重新看动作名称与字段说明。创建、恢复和覆盖是不同操作。

完成后可删除整个 `HSE2-练习` 临时目录；删除前确认其中没有需要保留的文件。
