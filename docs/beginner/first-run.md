# 第一次使用：加密、解密并核对一个练习文件

- **预计时间：**约 10 分钟
- **适用对象：**第一次使用主图形界面的 Windows 用户
- **需要准备：**已解压的 Windows ZIP、可删除的练习目录、一个文本编辑器
- **练习数据：**虚构文字和虚构口令；不要选择真实资料

本练习会在本机创建一个文本文件，对它加密，再解密为同一文件夹中的另一个文件并人工核对内容。不会连接云端。加密和解密都需要你记住同一个练习口令；忘记口令时，本练习没有找回办法。

## 1. 准备练习文件

1. 在“文档”中创建文件夹 HSE-练习。
2. 在 HSE-练习 中创建 示例.txt，写入一段虚构内容，例如：这是用于加密练习的虚构内容。，保存并关闭。
3. 记下 HSE-练习 的位置。应用会把加密和解密输出放在输入文件旁边。

## 2. 加密练习文件

1. 双击 high-security-encryptor-gui.exe，进入“快速使用”页签。
2. 在“我要”选择“加密”。点击“选择文件”，选择 HSE-练习\示例.txt。
3. 在“主加密密码”输入一个只用于本练习的虚构口令，并在“确认主加密密码”再输入一次。确认两次完全相同。
4. 点击“一键开始”。如果出现路径或确认提示，核对输入确实是练习文件后再继续。
5. 等待日志显示成功。记下日志报告的加密输出路径；不要移动或删除原始 示例.txt。单文件加密输出为 .hse 文件。

**预期结果：**原始文件仍在原位置，旁边另有一个加密输出文件。界面提示成功不等于已验证能恢复，因此继续下一步。

## 3. 解密并核对

1. 仍在“快速使用”页签，将“我要”改为“解密”。
2. 点击“选择文件”，选择上一步日志显示的加密输出文件。
3. 输入加密时使用的同一个练习口令。解密时不需要再次确认口令。
4. 点击“一键开始”，等待日志报告成功和恢复后的文件位置。
5. 等待日志报告恢复后的文件位置。解密结果会放在密文旁边；由于原名的原文件还存在，程序会选用另一个可用名称，例如 示例 (1).txt。
6. 用文本编辑器分别打开原始文件和恢复文件，确认文字逐字一致。这是人工内容核对，不是独立校验工具。确认后，可删除整个 HSE-练习 文件夹；删除前确认里面没有需要保留的文件。

## 常见问题

| 现象 | 可能原因 | 安全处理 |
|---|---|---|
| 加密提示两次口令不一致 | 确认栏输入有误 | 重新输入同一个虚构练习口令，再开始 |
| 解密认证失败或口令错误 | 选错了加密文件，或口令与加密时不一致 | 停止重复尝试；确认选择的是本次输出，并检查键盘布局和练习记录 |
| 输出文件已存在 | 该路径已有同名文件 | 不要为通过练习而覆盖未知文件；选择另一个空的练习目录或改用新的输入文件名 |
| 操作失败 | 路径不可用、文件被占用或权限不足等 | 保留原始练习文件，阅读日志中的具体错误；修正路径后再试 |
| 忘记练习口令 | 加密口令不可由程序替你找回 | 删除练习输出并重新从虚构文件开始；不要换真实文件尝试 |

## 这次操作中的名词

- **加密：**把可读内容变成需要口令才能恢复的密文文件。
- **解密：**用对应口令验证并恢复文件内容。
- **输入/输出：**输入是本次要处理的文件；输出是程序新生成的文件。程序默认避免覆盖已存在输出。
- **认证失败：**口令不对、文件损坏或文件与口令不匹配时，程序无法确认数据有效；不要把失败输出当作已恢复文件。

更多名词见[术语索引](glossary.md)。这只是主 GUI 的入门练习；批量任务、HSE2 归档、wrapper、访问禁用和 BitLocker 各有不同输入及风险，不能直接套用本练习。
