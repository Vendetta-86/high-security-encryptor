# v5 双视图归档：创建、校验、预览和恢复

- **预计时间：**约 20 分钟
- **适用对象：**已经完成[首次加密练习](first-run.md)的用户
- **需要准备：**独立 HSE2 GUI、两个可删除的样例文本文件、一个空的练习目录
- **练习数据：**虚构文件内容和两组不同的虚构口令；不要使用真实敏感资料

v5 是实验性 HSE2 格式。本教程用同一个归档保存两组公开定义的备用内容视图，分别由不同口令访问。它不隐藏第二个视图，不提供也不承诺可否认性、抗胁迫或反取证。实验格式不适合保存唯一副本。

HSE2 GUI 将输入交给项目已有的 HSE2 工作流执行。创建时每个视图通过“归档路径=源文件路径”映射一个文件；恢复输出为新目录。不要把日志里的“命令成功”当成恢复内容已比对。

## 1. 准备两个样例

1. 创建临时文件夹 HSE-v5-练习。
2. 在里面创建 primary.txt 和 secondary.txt，分别写入不同的虚构文字并保存。
3. 另准备两个不同的虚构口令：一个只用于 primary 视图，一个只用于 secondary 视图。记住哪个口令对应哪个文件。
4. 选一个新输出路径，例如 HSE-v5-练习\practice.hse2。不要选择已有文件。

## 2. 创建 v5 归档

1. 打开 high-security-encryptor-hse2-gui.exe，在“操作”中选择“实验性 HSE2 v5 双视图创建”。
2. 在“输出文件”选择刚才准备的 practice.hse2 路径。
3. 在“Primary 文件映射”输入：归档路径 primary.txt=完整路径\primary.txt。等号左边是归档内恢复时的相对文件名，右边是电脑上的源文件路径。
4. 在“Secondary 文件映射”输入：归档路径 secondary.txt=完整路径\secondary.txt。
5. 输入 primary 口令并确认，再输入不同的 secondary 口令并确认。两组口令都必须记住，且不能相同。
6. 确认输入路径和输出路径后点击“运行 HSE2 实验操作”。创建操作会生成新归档；原始两个文本文件仍保留。
7. 查看界面结果和输出路径，确认 practice.hse2 已生成。

**预期结果：**新归档包含两个可分别解锁的视图。若映射路径格式错误、口令未确认或两组口令相同，先修正输入；不要删除样例文件。

## 3. 对两个视图分别做完整校验

完整校验读取并认证所选视图的活动加密记录，不会把恢复后的明文写到磁盘。

1. 在“操作”选择“实验性 HSE2 v5 完整校验（不写明文）”。
2. 选择 practice.hse2，在“归档密码”输入 primary 口令，然后运行。
3. 确认结果显示该视图校验成功且没有写出明文。
4. 使用同一归档再运行一次，改用 secondary 口令。

两个视图必须分别验证。错误口令或校验失败时停止，不要继续恢复或把失败结果当成可用备份。校验成功说明本次所选视图的认证记录和长度检查通过；它不比较归档内保存的明文摘要，因为 v5 没有这种摘要字段。

## 4. 预览并恢复 primary 视图

1. 选择“实验性 HSE2 v5 恢复预览”。
2. 输入 practice.hse2、primary 口令，并把输出路径设为一个尚不存在的新文件夹，例如 HSE-v5-练习\restore-primary。
3. 运行预览。查看文件数、字节数、chunk 数、目标目录冲突和磁盘剩余空间。此预览会认证所选视图的元数据，但不会逐个认证所有 payload 记录；第 3 节的完整校验承担了完整记录认证。
4. 若目标路径已存在、空间不足或预览内容不是预期值，停止并选择合适的新目标。不要为了继续而覆盖未知文件。
5. 选择“实验性 HSE2 v5 单视图恢复”，填写同一个归档、primary 口令和刚才预览过的输出目录，运行恢复。
6. 查看结果日志并打开恢复目录中的文件，逐字核对与原始 primary.txt 一致。

## 5. 恢复 secondary 视图

对 secondary 视图重复第 4 节，使用 secondary 口令和另一个新目录 restore-secondary。确认恢复内容与原始 secondary.txt 一致，且与 primary 的内容不同。

## 结果、错误与清理

| 结果或现象 | 含义和处理 |
|---|---|
| v5 创建成功 | 输出了新的归档；样例原件仍在，继续分别校验和恢复两个视图。 |
| 完整校验失败 | 口令不匹配、归档数据损坏或其他认证条件失败；保留归档副本，停止写入操作。 |
| 预览报告目标冲突或空间不足 | 预览目标不是空的新目录，或所在磁盘空间不足；换一个新目录或释放空间后重新预览。 |
| 恢复失败 | 保留原归档和两个样例文件，阅读错误日志；修正口令或目标路径后重新操作。 |
| 两个口令相同 | 创建会被拒绝；选择两组不同的虚构练习口令再创建。 |

确认两个恢复文件内容都正确后，可以删除 HSE-v5-练习 整个临时文件夹。删除前确认没有需要保留的资料。真实归档应始终保留独立备份；本教程的操作结果不构成密码学认证或安全审计。

## 这些动作的区别

- **完整校验（v5-verify）：**认证所选视图的完整活动内容，不写出明文。
- **预览（v5-preview）：**检查恢复视图的元数据、目标冲突和空间；不认证每个 payload 记录。
- **恢复（v5-open）：**再次执行目标和空间预检，然后把所选视图文件写到目标目录。预览不能替代恢复时的预检。
- **双视图：**归档里有两个被公开定义的视图；它们分别使用不同口令访问，不代表隐藏其中任何一个。

后续变更口令、替换单个视图、compact 和 v4→v5 导出有独立操作语义，完成教程前不要把它们当成创建/恢复的同义操作。详细命令参考见[HSE2 CLI 工作流](../hse2_cli_workflows.md)。
