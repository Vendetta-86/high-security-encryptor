# 独立 HSE2 GUI：生成并使用 keyfile

本练习会生成一个随机 keyfile，用它创建普通 HSE2 v2 归档，再用同一个 keyfile 校验和恢复。keyfile 是解锁秘密：拿到文件的人可以尝试使用它解锁归档；丢失 keyfile 可能导致无法恢复。本练习只用临时样例。

## 1. 准备临时目录

在桌面创建 `HSE2-keyfile-练习`，并在其中创建：

```text
HSE2-keyfile-练习/
├─ 待加密/
├─ keyfile/
├─ keyfile-备份/
└─ 恢复结果/       （先不要创建，留给程序输出）
```

在 `待加密` 中创建 `练习.txt`，写入 `keyfile practice`。不要使用真实资料或真实口令。

## 2. 生成 keyfile 并制作练习副本

1. 打开独立 HSE2 GUI，选择“生成 keyfile”。
2. “输出文件”填 `HSE2-keyfile-练习\keyfile\practice.key`。
3. “keyfile 大小”保留默认值，运行操作。不要启用“允许覆盖输出文件”。确认界面报告生成成功。
4. 在文件资源管理器中把 `practice.key` 复制到 `keyfile-备份` 文件夹，副本仍命名为 `practice.key`。两个文件应大小相同。
5. 保留原件和副本，不要编辑 keyfile 内容。日常使用时应将备份放在与归档分开的安全位置，并确认备份确实可读；此处同一练习目录仅用于可删除的演练，不代表真实备份策略。

## 3. 用 keyfile 创建归档

1. 选择“创建 HSE2 归档”。
2. “要加密的文件夹”选择 `待加密`；“输出文件”填练习目录下的 `practice.hse2`。
3. “容器格式版本”保留 `2`，“归档密码安全等级”保留“推荐高安全”。
4. 在 `keyfile` 字段选择 `keyfile\practice.key`。本练习使用 keyfile 单独解锁，因此“归档密码（可选）”和“确认归档密码”都留空。不要勾选覆盖；保留创建后校验选项。
5. 运行操作，确认 `practice.hse2` 已创建。

## 4. 用 keyfile 校验和恢复

1. 选择“完整校验 HSE2 归档”，输入 `practice.hse2`，在 `keyfile` 字段选择同一个 `keyfile\practice.key`，运行。成功表示本次归档内容通过认证；不会写出明文。
2. 选择“解密并打开 HSE2 归档”，仍选择同一个归档和 keyfile；输出路径填尚不存在的 `恢复结果` 文件夹。
3. 保留“打开前完整校验归档”选项，不启用覆盖，然后运行。
4. 打开恢复结果中的 `待加密\练习.txt`，确认内容为 `keyfile practice`。原始文件、归档、keyfile 和备份副本都应仍存在。
5. 再用 `keyfile-备份\practice.key` 对练习归档执行一次完整校验。这能确认这个练习副本可读取并与归档匹配；它不等于对真实离线备份位置进行恢复演练。

## 5. 重要限制

- 只有 keyfile 的归档要求持有该 keyfile。若创建时组合使用口令和 keyfile，打开时也需要按该归档的 wrapper 配置提供相应因子。
- 不要把 keyfile 与 `.hse2` 归档放在同一文件夹；不要通过邮件、聊天或公开网盘传送真实 keyfile。
- 不要覆盖现有 keyfile：生成新的随机 keyfile 不会自动更新任何旧归档。旧归档仍需要创建时对应的 keyfile。
- “HSE2 keyfile 轮换”会处理配置中所列归档及其凭据，属于另一项变更操作。本入门练习不执行轮换；开始前应先读专门文档并保留输入归档副本。

完成并确认不再需要练习文件后，可删除整个临时练习目录。
