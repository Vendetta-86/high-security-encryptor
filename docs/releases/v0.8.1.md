# v0.8.1

This patch release improves first-run onboarding by shipping the current beginner guide set with the Windows ZIP. The package includes the beginner guide index, feature inventory, glossary, and step-by-step practice guides for the supported GUI and CLI workflows.

No encryption format, cryptographic primitive, or default-format behavior changes in this release. HSE2 v5 remains an experimental alternate-content format. The project makes no plausible-deniability, coercion-resistance, or secure-erasure claims.
