# v0.8.4

This patch release improves HSE2 v5 maintenance coverage and GUI guidance.
The Windows package now exercises the remaining v5 maintenance operations in
an isolated temporary directory. The beginner maintenance guide documents all
eight GUI actions, their inputs, password sources, and destination paths. GUI
output labels now identify restore and preview directories accurately.

HSE2 v5 remains experimental and explicitly disclosed as a two-view format. It
does not claim plausible deniability, coercion resistance, anti-forensics, or
secure erasure. This release does not change the default HSE2 creation format.
