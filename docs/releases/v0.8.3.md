# v0.8.3

This patch release hardens removable BitLocker operations and improves their
user guidance. Encryption, unlock, and lock actions now check the reported
volume state before invoking BitLocker, including automatic-unlock state that
prevents locking. Recovery-file flush failures are covered by isolated failure
injection and retry tests.

HSE2 v5 remains experimental and explicitly disclosed as a two-view format. It
does not claim plausible deniability, coercion resistance, anti-forensics, or
secure erasure. This release does not change the default HSE2 creation format.
