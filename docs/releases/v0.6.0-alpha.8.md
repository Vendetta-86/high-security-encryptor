# v0.6.0-alpha.8

**Status: release candidate preparation; not published.**

This alpha packages the current HSE2 archive workflows after `v0.6.0-alpha.7`.

## Highlights

- Adds HSE2 v3 streaming archive support while retaining v2 read/write compatibility.
- Adds authenticated archive validation, including a standalone Windows helper executable.
- Extends the HSE2 GUI with create, restore, validate, metadata preview, masked in-memory password entry, and a guided create-to-restore path.
- Allows restore staging to use `HSE2_RESTORE_TEMP_DIR` when it is an existing directory on the same filesystem as the restore destination.
- Rejects noncanonical manifest paths and restore entries that collide under Windows path normalization before creating output files.
- Rejects Windows alternate-data-stream syntax, reserved device names, and filename components Win32 would reinterpret before restoring files.
- Records the Phase 8 decoy/duress feature as deferred pending a separate format proposal and independent cryptographic review. This alpha makes no plausible-deniability claim.
