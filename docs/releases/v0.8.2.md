# v0.8.2

This patch release fixes removable-drive BitLocker status handling and improves
the recovery flow. PowerShell diagnostics no longer break status JSON parsing;
an already protected or converting drive is reported as an existing state
instead of as a failed encryption attempt; and a locked removable drive can be
unlocked when Windows reports its protection state as unknown.

The Windows GUI now makes it clear when BitLocker protection is already active
so users do not start encryption again. Recovery information is saved before
encryption begins.

No HSE2 format or cryptographic behavior changes in this release. HSE2 v5
remains experimental and does not claim plausible deniability, coercion
resistance, or secure erasure.
