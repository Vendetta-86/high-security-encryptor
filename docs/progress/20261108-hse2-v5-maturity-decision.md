# HSE2 v5 成熟度决策

- 日期：2026-11-08
- 对应路线图：[HSE2 Roadmap 4.0](20261107-hse2-roadmap-4.0.md)
- 决策：**HSE2 v5 继续标记为实验性格式。**

## 决策范围

本记录只决定 v5 当前的成熟度标签和默认格式边界，不是密码学证明、认证或新格式批准。v5 继续作为明确披露的双视图备用内容格式；不宣称隐藏卷、可否认性、抗胁迫、反取证或安全擦除。v2/v3/v4 兼容行为和默认创建格式保持不变。

项目按用户已经确定的自用范围执行，本决策不把第三方认证或独立外部审查重新设为发布门槛。是否可升级稳定标签，依据本仓库能复跑的格式兼容、错误处理、回归和发布证据决定。

## 本次核验的证据

### 自动化测试

在当前工作树运行：

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_hse2_v5_fixtures tests.test_hse2_v5_codecs tests.test_hse2_v5_workflows tests.test_hse2_v5_restore_staging tests.test_hse2_v5_cli
```

结果：42 项通过，退出码 0。覆盖范围包括：

- 固定 header/footer 字节及字段边界、KDF/HKDF 与 AES-GCM 确定性向量；
- 视图凭据隔离、记录认证字段、描述符验证、路径/长度/重叠及畸形输入限制；
- 创建、单视图替换、双视图压缩、v4 导出迁移、恢复暂存、错误密码和篡改失败；
- 写入、flush、replace、空间不足等失败路径中的源文件保留、部分输出清理与重试行为；
- CLI 命令注册、密码确认、迁移所需双口令和拒绝不安全路径。

本结果只代表本机定向测试；它不等于 Windows 发布包或跨环境互操作验证。

### 格式兼容与固定夹具

- `tests/fixtures/hse2` 有 v2、v3 历史归档夹具。
- `tests/fixtures/hse2_v5` 当前有 `public_header.hex` 和 `footer.hex`，并由 `tests.test_hse2_v5_fixtures` 校验。
- 当前没有完整冻结的 v5 容器二进制归档作为跨提交读取兼容夹具。确定性原语、header/footer 和构造工作流测试有价值，但不能完全替代一个长期保存、可在新实现中重新读取的完整归档。
- 本次没有重新运行 v2/v3/v4 全量兼容测试；阶段 5 的全套回归仍需执行。

### 设计与使用边界

`20261101-hse2-v5-format-design.md` 明确 v5 会公开总容器长度、双视图描述符位置和长度、更新增长；没有填充，也没有回滚保护或安全擦除保证。单视图更新保留对侧视图的活动数据，但历史加密记录可能留在文件中。空间回收需要同时提供两个视图口令并写入新归档。

`20261102-hse2-v5-baseline-10run.md` 记录了 10 次本机独立进程测量，样本包含最大 64 MiB 输入，工作集约 98 MiB 且未随输入线性增长。记录自身也限定这是 Windows 11 / Python 3.13.15 上的本机观察结果，不是跨机器性能承诺或硬阈值；v4 旧基线测量边界不同，不宜直接比较。

阶段 3 的公开资产报告验证的是 v0.8.2 的公开 ZIP、摘要、解压、CLI `--help` 和 GUI `--smoke-test`。它确认该 tag 的发布资产可用，不验证之后的 v5 源码变更已进入发布包。

## 继续实验性的理由

本地测试覆盖面已足以支持继续开发和受控自用试验，但目前没有完整的冻结 v5 归档兼容夹具，也没有本路线图范围内“当前 v5 源码对应的精确发布包”验收证据。对新归档格式而言，固定完整容器有助于发现字段、编码或版本分派的非预期漂移；阶段 5 还需要把全量兼容回归和发布资产证据对齐。因此现在提升到稳定标签会超出现有证据。

这不是说已发现 v5 功能缺陷，也不否定 42 项定向测试；这是对兼容与交付证据成熟度的限制。

## 后续重新评估条件

重新讨论稳定标签前，至少完成以下本地可验证工作：

1. 添加一个完整、固定字节的最小 v5 归档夹具；新版本必须读取该夹具并恢复预期文件，同时拒绝修改关键 framing、描述符或记录认证字段的副本。
2. 对 v2/v3/v4 历史归档执行完整只读兼容回归，确保 v5 格式分派不改变旧版本读取和默认创建行为。
3. 将当前源码提交、版本/标签、Windows 构建包、公开下载资产摘要和启动冒烟结果关联到同一份可追溯报告。
4. 让 CLI、GUI、新手教程和发布说明持续明确实验性与双视图边界；不加入隐含可否认性或安全擦除承诺。

这些条件完成后可以重新审议标签；完成条件本身不自动触发默认格式切换。任何默认创建格式变化必须单独记录决策。
