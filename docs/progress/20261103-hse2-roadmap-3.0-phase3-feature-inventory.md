## 3. CLI 用户功能

主入口：安装后的 `high-security-encryptor` 或源码运行 `python -m high_security_encryptor`。

### 通用命令

- 批量加密/解密：`encrypt-batch`、`decrypt-batch`
- 配置检查与模板：`validate-config`、`init-example`
- 本地 keyfile：`generate-keyfile`
- Windows DPAPI 文件保护：`dpapi-protect`
- HSE1 到 HSE2 迁移：`hse1-to-hse2`
- HSE2 单文件、配置和批量加解密/重包：`hse2-encrypt`、`hse2-decrypt`、`hse2-rewrap`、`hse2-encrypt-config`、`hse2-decrypt-config`、`hse2-rewrap-config`、`hse2-batch-encrypt`、`hse2-batch-decrypt`、`hse2-batch-rewrap`
- HSE2 批量校验、检查和归档规划：`hse2-validate`、`hse2-inspect`、`hse2-plan-archive`

### `hse2` 子命令

- 元数据和校验：`inspect`、`validate`、`validate-archive`
- keyfile 检查：`keyfile inspect`
- wrapper：`wrapper list/add/remove/rewrap`
- 访问销毁：`access destroy`
- v4：`v4-create/open/replace`
- v5：`v5-create/open/verify/preview/password-update/replace/compact`
- 格式迁移：`v4-to-v5`

具体选项和风险以 `high-security-encryptor <command> --help` 与 `docs/hse2_cli_workflows.md` 为准。新手教程先展示安全的交互式密码提示；`--password-stdin` 和 JSON 密码 provider 放入专门的自动化章节，不建议把密码放到命令行参数或 shell 历史。

## 5. 新手教程与术语索引的最小覆盖集

### 分步教程

1. 下载、解压、启动两个 GUI，认识窗口和执行日志。
2. 使用主 GUI“快速使用”页签加密一个练习文件，再解密并人工比对恢复内容。
3. 使用多文件入口处理一个练习批次；理解输出路径、扩展名和“不覆盖已有文件”。
4. 做一个多文件任务；区分文件密码、批次 metadata 密码和配置文件。
5. 使用“检查配置”与“生成配置”；读懂通过、警告、错误和退出码。
6. 选择兼容/强化/不保存密码表模式，并根据自己的恢复能力作选择。
7. 管理 HSE2 keyfile、wrapper 和 header backup；演练用副本恢复，不以真实数据做破坏性练习。
8. 使用 HSE2 创建、打开、校验与元数据检查；说明密码、keyfile、DPAPI 的不同。
9. 理解 v4/v5 的实验入口；在隔离样例上预览、校验、替换、compact、迁移和更新视图密码。
10. 使用可移动存储 BitLocker 页面前，确认目标盘符、管理员权限和恢复密钥保存位置。
11. CLI 基础：`--help`、配置路径、密码隐藏提示、输入/输出路径、错误后的安全恢复。
12. CLI 自动化：JSON provider、stdin、报告文件与脚本退出码；单独解释凭据放置风险。

### 术语索引候选项

加密/解密、明文/密文、随机数、salt、nonce、认证标签、认证加密、chunk、流式处理、manifest、descriptor、header/footer、归档路径、root key、credential slot、wrapper、KDF、Argon2id、compatible/hardened/no-password-tables、文件密码、metadata 密码、keyfile、DPAPI、BitLocker、header backup、HSE1/HSE2、v2/v3/v4/v5、verify、preview、replace、compact、迁移。

每个术语页面条目必须回答：它是什么、用来解决什么、程序大致怎么处理、用户在哪会看到它、需要准备什么、限制/风险是什么，并链接到一个可跟做任务。GUI 字段旁的短帮助只保留当前决策需要的信息，细节指向索引。
