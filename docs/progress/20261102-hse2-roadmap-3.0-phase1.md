# HSE2 Roadmap 3.0 Phase 1 Implementation Record

**状态：完成**  
**日期：2026-11-02**

## 交付内容

- 新增 `hse2 v5-verify`：认证所选 v5 视图的 descriptor 与每条活动 payload record，核对每个文件的认证块长度合计；逐块处理，不输出或保存恢复后的明文。
- 新增 `hse2 v5-preview`：认证所选视图 descriptor，报告文件数、明文总字节数、chunk 数、恢复目录是否已存在及目标卷当前可用空间；不写文件。
- 恢复 GUI 在用户确认 v5-open 前执行预览，把摘要放入确认框；认证失败、目标目录已存在或已知空间不足时取消恢复。恢复 workflow 自身在建立 staging 前再次检查目标目录和可用空间。
- GUI 增加独立的完整校验和预览入口。GUI 密码仅通过受控 secret inputs 传递，不进入 argv 或日志；CLI 支持隐藏式密码提示及 `--password-stdin`。
- 更新 [`HSE2 CLI 工作流说明`](../hse2_cli_workflows.md)，解释两项命令差别、空间检查边界和格式限制。

## 验收证据

- `v5-verify` 对正确口令和完整 payload 成功；篡改记录、截断容器和错误口令失败；测试确认没有恢复文件落盘。
- `v5-preview` 报告所选视图的文件、字节、活动块数、目标状态与空间估算，且不创建目标。
- GUI 恢复确认测试验证预览被调用、统计信息出现在确认内容、密码未进入 argv；目标已存在时不弹出继续确认并阻止恢复。
- ENOSPC 注入验证恢复未建立正式输出目录即失败；现有 v5 codec 测试覆盖文件数、活动 chunk 数和 descriptor 尺寸上限。
- 定向测试：120 项通过。
- 全量测试：`python -m unittest discover -s tests`，769 项通过、6 项跳过，52.412 秒。
- `git diff --check` 通过。

## 已知边界

- v5 格式不存储明文摘要；完整校验认证记录并检查长度一致性，不声称与归档内 plaintext digest 比较。
- 预览只解锁并验证 descriptor，不遍历 payload。需要完整 payload 完整性检查时使用 `v5-verify`。
- 目标卷可用空间是检查时的估值，之后可能变化；恢复 workflow 会在开始 staging 前再次检查，但空间估值不能保证设备后续不会返回 ENOSPC。
- 完成功能和本地测试不构成独立密码学认证，也不改变 v5 的实验性状态、公开双视图语义或不承诺可否认性的边界。
